# Папка для видео — инструкция

Видео, которые не хочется выкладывать на YouTube, можно положить прямо на сайт.

## Как добавить видео к стихотворению / записи

1. Положи `.mp4`-файл в эту папку (`videos/`). Имя файла — латиницей, без пробелов, например `moe-video.mp4`.
2. Открой нужный `section-*.txt` (текст записи) и добавь строку с путём к файлу — лучше всего сразу под заголовком:
   ```
   videos/moe-video.mp4
   ```
   Или, если запись уже использует директивы с `#`, добавь строку:
   ```
   #video: videos/moe-video.mp4
   ```
   (обе формы работают во всех разделах: стихи, новинки, авторская, сказки)
3. Можно указать и прямую ссылку на `.mp4` в интернете — тоже сработает.
4. Закомить и запушить — сайт обновится сам через пару минут.

## Как это выглядит

- Видео показывается в карточке записи с кнопками проигрывателя (пуск, громкость, полный экран).
- Работает на телефоне и компьютере.
- Кнопки «Поделиться» и «Копировать» продолжают работать как раньше (делятся ссылкой на запись, а не на YouTube).

## Советы

- Формат: `.mp4` (H.264) — его понимают все браузеры.
- Размер: чем меньше файл, тем быстрее грузится. До 50–100 МБ — нормально.
- Первый кадр видео станет обложкой автоматически.
